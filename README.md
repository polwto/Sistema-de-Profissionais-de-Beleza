# 💇‍♀️ Sistema de Profissionais de Beleza

Projeto desenvolvido em **Java** com o objetivo de praticar conceitos fundamentais de programação através de um sistema interativo de profissionais de beleza.

## 📌 Sobre o projeto

O sistema permite que o usuário escolha uma cidade do **Rio Grande do Sul** e visualize os profissionais disponíveis naquela região.

Após escolher um profissional, o usuário pode visualizar suas informações, como experiência, especialização e serviços realizados. Também é possível acessar as informações de contato para solicitar um agendamento.

## ✨ Funcionalidades

* Escolha de cidade:

  * Porto Alegre
  * Canoas
  * Pelotas
* Visualização dos profissionais disponíveis em cada cidade
* Seleção de um profissional
* Visualização de:

  * Nome
  * Experiência
  * Especialização
  * Serviços realizados
* Consulta de e-mail e WhatsApp para agendamento
* Opção de voltar ao menu
* Opção de encerrar o sistema

## 🛠️ Tecnologias utilizadas

* **Java**
* `Scanner`
* Estruturas condicionais `if / else if / else`
* Estrutura de repetição `while`
* Métodos
* Variáveis e parâmetros
* Operadores de comparação
* Entrada de dados pelo terminal

## 🎯 Objetivo

O projeto foi desenvolvido como parte dos estudos de **Paradigmas de Programação**, buscando colocar em prática os conceitos aprendidos durante as aulas e desenvolver uma aplicação interativa utilizando Java.

## ▶️ Como executar

1. Tenha o **Java JDK** instalado no computador.
2. Clone ou baixe este repositório.
3. Abra a pasta do projeto no **VS Code** ou em outro editor.
4. Compile o programa:

```bash
javac Main.java
```

5. Execute:

```bash
java Main
```
